# 우리동네 청년혜택 — 연수구 데모

지자체(시군구) 단위로 흩어진 청년 혜택을 한곳에 모아, **나이·상황만 넣으면 받을 수 있는 것만**
골라주고 **최대 수령액을 합산**해 보여주는 데모.

> "옆 동네는 받는데 나만 몰랐던 우리 구 청년 지원금" — 발견의 쾌감 = 공유 동력.

## 실행
```
# 그냥 브라우저로 열면 됨 (빌드 불필요)
open youth-benefits-demo/index.html      # mac
# 또는
python3 -m http.server 8000              # http://localhost:8000/youth-benefits-demo/
```

## 데모 포인트 (사람들이 "좋아!" 하는 지점)
- **나이 입력 + 상황 토글**(무주택/구직중/재직중/별거) → 조건 충족 혜택만 ✅, 안 맞는 건 🔒 + 이유 표시
- **"최대 OOO만원 받을 수 있어요"** 합산 배너 → 도파민 + 카톡 공유 버튼
- 각 혜택: 금액 · 신청 D-day · 문의처 · 공식 출처 링크

## 데이터
- `data/yeonsu_youth.json` — 인천/연수구 청년 혜택 6종 실제 공개정보 기반 시드(2026-06-08 스냅샷)
  - 청년월세 / 드림체크카드 / 면접수당 / 드림For청년통장 / 재직청년 복지포인트 / 마음건강
- 출처: 인천청년포털·연수구청·복지로 공개 페이지

## 수집 자동화 (핵심 해자)
- `scraper/scrape.py` — 공고 수집 → LLM 구조화 → JSON 파이프라인의 골격
- **현실**: 정부/지자체 사이트는 직접 크롤이 **HTTP 403으로 차단**됨(이번 데모에서 실제로 막힘).
  실서비스는 ① 공식 오픈API(data.go.kr·온통청년) ② 제휴 ③ 합법적 수집+캐싱 조합 필요.
  → 진짜 승부처는 기술이 아니라 **데이터 수집·최신화**임을 그대로 보여줌.

## 확장 로드맵
1. 지역 확장: 연수구 → 인천 10개 군·구 → 전국 229개 (수집 파이프라인 일반화)
2. 페르소나 확장: 청년 → 신혼·출산 / 소상공인 / 어르신
3. 알림: "신청 D-7" 푸시로 놓친 돈 회수
4. 수익: 발견 무료 + 신청 서류대행 업셀, 지자체·지역업체 제휴
