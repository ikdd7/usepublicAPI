# 🧧 경조사비 도우미 (Gyeongjosa Helper)

> **"발칙한 숨은 니치마켓"** + **"내 클릭 한 번이면 굴러가는 자동 수익 구조"** 를 처음부터 끝까지 실제로 구현한 프로젝트.
>
> 축의금·부의금 적정 금액을 추천하고, 봉투 한자 문구와 전달 메시지까지 만들어주는 **무료 도구**를 미끼로,
> **프리미엄 봉투 PDF팩 + 에티켓 가이드**를 자동 판매하는 **백엔드 0개, 정적 배포** 깔때기입니다.

---

## ⚠️ 먼저, 솔직한 전제

"클릭 한 번에 자동으로 돈이 무한 생성되는 마법"은 없습니다. 이 프로젝트가 만드는 것은:

> **한 번 셋업(결제계정 연결)해두면, 당신의 "배포 클릭" 이후로는
> 트래픽이 깔때기를 자동으로 통과하며 결제·전달이 사람 손 없이 일어나는 구조.**

당신이 직접 해야 하는 **1회성 작업**은 딱 둘입니다 — ① 결제계정(Gumroad 등) 만들고 링크 붙여넣기, ② 배포 버튼 누르기.
그 이후의 결제·다운로드 전달·정산은 자동입니다. (트래픽 유입은 SEO/공유로 시간이 듭니다 — 이건 정직하게 말합니다.)

## 🧩 기술 구조 (의도적으로 "운영 부담 0")

- **순수 정적 사이트** (HTML/CSS/Vanilla JS) — 서버·DB·빌드 없음
- 추천 로직은 `assets/engine.js`의 **순수 함수** (테스트·수정 쉬움)
- 결제는 **외부 호스티드 체크아웃**(Gumroad/Lemon Squeezy) 링크 한 줄 — PG 직접 연동/정산 책임 없음
- 운영 변경은 `assets/config.js` **값만 수정** → push → 자동 배포

```
index.html              랜딩 + 도구 + SEO 콘텐츠(FAQ/기준표)
assets/config.js        ★ 결제링크·가격·제휴링크 (여기만 고치면 됨)
assets/engine.js        경조사비 추천 엔진 (휴리스틱)
assets/app.js           UI·이벤트·프리미엄 깔때기·무료 봉투 인쇄
assets/styles.css       디자인
premium/                실제 판매할 상품 시드 (Gumroad에 업로드)
  ├─ 메시지_100선.md
  ├─ 경조사_에티켓_가이드.md
  └─ 봉투_인쇄_템플릿.html
.github/workflows/      push 시 GitHub Pages 자동 배포
vercel.json / netlify.toml   다른 호스팅용 설정
```

## 🚀 당신의 "클릭 한 번" — 배포 & 수익화 (3단계)

### 1단계: 상품 만들고 결제 링크 받기 (약 10분, 1회성)
1. [Gumroad](https://gumroad.com) 또는 [Lemon Squeezy](https://lemonsqueezy.com) 가입
2. 새 디지털 상품 생성 → `premium/` 폴더의 파일들을 PDF로 변환해 업로드
   - `.md` 파일은 [Typora/Dillinger]로 PDF 내보내기, `.html`은 브라우저에서 '인쇄 → PDF로 저장'
3. 가격 ₩4,900 설정 → **구매 링크 복사**

### 2단계: 링크 붙여넣기 (1분)
`assets/config.js` 열어서:
```js
CHECKOUT_URL: "https://your-id.gumroad.com/l/gyeongjosa-pack",
```
→ 비어있던 "준비중" 버튼이 **즉시 "지금 받기" 결제 버튼으로 켜집니다.**

### 3단계: 배포 (← 이게 당신의 "클릭 한 번")
- **GitHub Pages (무료, 추천)**: Settings → Pages → Source = **GitHub Actions** 설정.
  이후 `git push`만 하면 `.github/workflows/deploy.yml`이 **자동 배포**.
- 또는 **Vercel/Netlify**: 저장소 import → Deploy 클릭 (빌드 설정 불필요).

> 이후로는 끝. 방문자가 결제하면 Gumroad가 자동으로 파일 전달 + 정산.

## 🔁 8명 페르소나 × 5단계 재귀 검토

각 단계를 8개 관점으로 검토하고, 치명적 지적은 **이전 단계로 되돌려(재귀)** 설계에 반영했습니다.
전체 검토 로그는 **[PERSONA_REVIEW.md](PERSONA_REVIEW.md)** 참조.

**8 페르소나**: ①시장분석가 ②실사용자(김대리) ③UX디자이너 ④그로스해커 ⑤수익화전략가 ⑥엔지니어 ⑦법무/리스크 ⑧악마의변호인

**재귀로 반영된 대표 변경점**:
- (법무→기획) PG 직접 연동 대신 **호스티드 체크아웃**으로 전환 (전자상거래·정산 리스크 제거)
- (실사용자→실행) "참석 시 식대 반영" 로직 추가 (실제 의사결정과 일치)
- (악마의변호인→기획) "금액 추천이 부담/오류 책임?" → 전 화면 **'참고용 가이드' 디스클레이머** 명시
- (그로스해커→실행) 무료 봉투 1장 인쇄 제공으로 **체류·공유·전환** 동시 강화
